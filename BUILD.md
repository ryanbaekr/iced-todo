# Building Iced-TODO for Linux

## Dependencies

- Install [rustup](https://www.rust-lang.org/tools/install)

- Install the necessary system libraries:

  ```sh
  script/linux
  ```

## Building from source

Once the dependencies are installed, you can build Iced-TODO using [Cargo](https://doc.rust-lang.org/cargo/).

For a debug build of the app:

```sh
cargo run
```
